How does this page reach you?

This is a static site: no database and no server-side code, just HTML files served exactly as they are.

  1. Your browser asks

    You open / or /blog/, and your browser sends an HTTP GET to the MyMiniCloud cluster.

  2. A web container answers

    The web server running in a container looks up the matching file, such as blog/index.html.

  3. The file comes back

    The file is returned unchanged. Light, fast, and easy to scale by adding containers when traffic grows.
